# vfs-shell

Эмулятор оболочки UNIX-подобной ОС с виртуальной файловой системой.
Практическая работа № 1 по дисциплине «Конфигурационное управление»,
вариант 14.

Документация дополняется по мере реализации этапов.

## Общее описание

Приложение с графическим интерфейсом (tkinter) имитирует работу в командной
строке UNIX-подобной ОС. Заголовок окна содержит имя виртуальной файловой
системы (VFS). Ввод разбирается на команду и аргументы, ошибки выполнения
выводятся в окно.

## Команды (этап 1)

| Команда | Описание                                   |
|---------|--------------------------------------------|
| `ls`    | заглушка: печатает своё имя и аргументы    |
| `cd`    | заглушка: печатает своё имя и аргументы    |
| `exit`  | завершает работу эмулятора (без аргументов) |

Ошибки: неизвестная команда (`foo: command not found`), незакрытая кавычка
(`parse error: ...`), лишние аргументы у `exit`.

## Сборка и тесты

Сборка не требуется (Python 3.8+, модуль `tkinter` из стандартной
библиотеки).

```
make run          # или ./run.sh, или run.bat
make test         # или ./run.sh test, или run.bat test
```

## Пример использования

```
$ ls -l docs
name: ls, args: ['-l', 'docs']
$ cd /usr
name: cd, args: ['/usr']
$ foo
foo: command not found
$ exit
```

## Параметры командной строки (этап 2)

| Параметр          | Описание                                                   |
|-------------------|------------------------------------------------------------|
| `--vfs PATH`      | путь к физическому расположению VFS                        |
| `--prompt TEXT`   | приглашение к вводу; `{vfs}` и `{cwd}` подставляются       |
| `--script PATH`   | стартовый скрипт с командами эмулятора                     |
| `--headless`      | без GUI: диалог выводится в консоль (для скриптов и CI)    |

По умолчанию приглашение имеет вид `{vfs}:{cwd}$ `. При запуске все
параметры выводятся в консоль и в окно с пометкой `[debug]`.

### Стартовый скрипт

Команды выполняются последовательно, на экране отображаются и ввод
(с приглашением), и вывод — как в диалоге с пользователем. Пустые строки
пропускаются, строки на `#` только отображаются. Ошибочная строка
выводит сообщение, помечается `[script] строка N: ошибка, строка
пропущена`, и выполнение продолжается. Команда `exit` завершает скрипт.
Если файл скрипта не найден, сообщение уходит в stderr, код возврата 1.
В режиме `--headless` без `--script` команды читаются из stdin.

### Скрипты проверки (реальная ОС)

В каталоге `scripts/` лежат скрипты `*.sh` и `*.bat`, вызывающие
эмулятор со всеми параметрами: `scripts/stage2_params.sh`.
Стартовые скрипты эмулятора лежат в `examples/startup/`.

```
$ ./run.sh --headless --prompt "me> " --script examples/startup/basic.txt
me> ls -l /home
name: ls, args: ['-l', '/home']
```
